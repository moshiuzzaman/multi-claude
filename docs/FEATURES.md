# ✨ Multi-Claude features

Everything Multi-Claude can do today. Each feature links to step-by-step help in the

## 👥 Accounts

#### 🧩 Several Claude accounts, side by side
Each account runs in its own Claude Desktop window, signed in and ready. No signing out and
in again to switch.
→ [Adding an account](GUIDE.md#adding-and-signing-in-to-an-account)

#### ▶️ One smart button
**Launch** when an account is closed, **Show** and **Close** when it's open. Always the right
action, in the same place.
→ [Opening and closing](GUIDE.md#opening-and-closing-accounts)

#### 🎨 A colour for every account
Pick a colour, and it shows on the account's card, its letter icon and its taskbar button, so
you can tell accounts apart at a glance.
→ [Rename, colour and shortcut](GUIDE.md#rename-colour-and-desktop-shortcut)

#### 🖱️ Desktop shortcuts
Open any account straight from your Desktop, without opening Multi-Claude first.
→ [Rename, colour and shortcut](GUIDE.md#rename-colour-and-desktop-shortcut)

#### ⚠️ Wrong-account warning
Tells you when two profiles are signed in to the same Claude account, and how to fix it.
→ [One account per profile](GUIDE.md#one-account-per-profile)

#### 🗑️ Safe delete
Removes an account's folder from this PC only, after several safety checks. Your Claude
account itself is never touched.
→ [Deleting an account](GUIDE.md#deleting-an-account)

## 📊 Usage

#### 📈 Usage limits for every account
Session and Weekly usage on every account's card, with no extra sign-in.
→ [Usage limits](GUIDE.md#usage-limits)

#### ⚡ Live limits *(optional)*
Up-to-the-minute figures with reset times, after one quick browser sign-in.
→ [Turning on live limits](GUIDE.md#turning-on-live-limits)

#### 🔔 Limit alerts
A notification when an account passes a level you choose, such as 80% of its weekly limit.
→ [Limit alerts](GUIDE.md#limit-alerts)

#### 🗓️ Usage history
Charts of the last 7 or 30 days, including when each limit was reached.
→ [Usage history](GUIDE.md#usage-history)

#### ⏱️ History and Storage
How long each account was open, and how much disk space each one uses.
→ [History and Storage](GUIDE.md#history-and-storage-pages)

## 💻 Claude Code

#### 🧑‍💻 Use in VS Code
Switches the Claude Code extension in your VS Code to any account, with no new sign-in.
→ [VS Code and terminal](GUIDE.md#using-an-account-in-vs-code-or-a-terminal)

#### ⌨️ Terminal
Opens Claude Code in a terminal as any account.
→ [VS Code and terminal](GUIDE.md#using-an-account-in-vs-code-or-a-terminal)

#### 💬 Claude Code chats `NEW`
See each account's Claude Code chats in one list, then continue or close any of them.
→ [Claude Code chats](GUIDE.md#claude-code-chats)

#### 📤 Copy a chat to another account `NEW`
Started a chat in the wrong account? Copy it to the right one, for its terminal, VS Code or
Claude Desktop's Code tab. The original stays where it was.
→ [Copying a chat](GUIDE.md#copying-a-chat-to-another-account)
